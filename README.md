# Rock Paper Scissors

A colourful Rock Paper Scissors game. Play against the computer and keep score.

## Play online
https://shikhateotia.github.io/rock-paper-scissors/

## How to play
Click Rock, Paper or Scissors. The computer picks at random, and the winner is shown after each round. The score keeps adding up until you press Reset score.

## Rules
- Rock smashes Scissors
- Scissors cuts Paper
- Paper covers Rock
- Same choice from both = tie

## Built with
- Python (original game logic)
- HTML, CSS and JavaScript (web version)
